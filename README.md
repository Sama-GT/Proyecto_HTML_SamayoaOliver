# 🎵 MusicStream

MusicStream es una interfaz web de transmisión de música construida usando HTML5 y CSS3.

El proyecto simula una plataforma de streaming moderna con catálogo de álbumes, páginas de detalle de álbumes, flujo de compras y panel de usuario con biblioteca.

---

## 🚀 Features

- Responsive design (Mobile & Desktop)
- Dark mode modern UI
- Album catalog with clickable cards
- Album detail pages
- Static music player
- Shopping cart flow
- Purchase confirmation page
- User library dashboard

---

## 🛠 Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS Variables
- Media Queries
